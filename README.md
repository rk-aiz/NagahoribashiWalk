# 長堀橋さんぽ 🗺️

大阪・長堀橋エリアのお店や観光スポットを探せる地域観光サイトです。

> **注意**: 本プロジェクトはグループ学習を目的として作成されたものです。

---

## 概要

カテゴリ別・キーワード検索でスポットを探せます。ログインするとお気に入り登録やレビュー投稿も可能です。

| 対象ユーザー | できること |
|---|---|
| 未ログイン | スポット一覧・カテゴリ別一覧・キーワード検索・詳細閲覧 |
| ログインユーザー | 上記 ＋ お気に入り登録・レビュー投稿／編集／削除 |
| 管理者 | 上記 ＋ スポット追加／編集／削除・レビュー管理・ユーザー管理 |

---

## 技術スタック

| カテゴリ | 技術 |
|---|---|
| 言語 | Java 21 |
| フレームワーク | Spring Boot |
| 認証 | Spring Security |
| ORM | MyBatis |
| テンプレートエンジン | Thymeleaf |
| データベース | PostgreSQL |
| IDE | Eclipse |
| バージョン管理 | Git / GitHub |

---

## 環境構築

### 前提条件

- Java 21 がインストールされていること
- PostgreSQL が起動していること
- Eclipse に Spring Tools 4 プラグインが導入されていること

---

## ブランチ運用ルール

```
master          # 本番相当。直接pushは禁止（PR必須）
feature/xxx     # 機能ごとの開発ブランチ
```

- 作業は必ず `feature/xxx` ブランチを切って開始する
- `master` へのマージは Pull Request を作成しレビューを受ける
- ブランチ名は機能一覧の「Gitブランチ」列に従う
